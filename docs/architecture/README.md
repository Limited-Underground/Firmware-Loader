# C4 model and local presentation

[workspace.dsl](workspace.dsl) is the single diagram model, mapped to source baseline **d74832b1d2579762fc1aea0634ce409a9e4c21ec** and the [architecture](../ARCHITECTURE.md). Stable view keys are LoaderContext, LoaderContainers and LoaderComponents.

The desktop process is the only application container. Windows file storage and target-project authorities are external boundaries. An amber component/relationship denotes synthetic host-only test injection, not production installation wiring. Target facts are source-embedded constants with external provenance, not build-time retrieval or runtime networking. No real device command path is modeled.

Use pinned official [Structurizr tools](https://docs.structurizr.com/getting-started/local-export-static-site) locally. Common foundation tooling owns the selected executable/version/hash. Do not upload to a cloud account or substitute a hand-drawn diagram while claiming successful parsing. Generated presentation is derived from this model.
