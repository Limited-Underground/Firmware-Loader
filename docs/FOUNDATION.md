## Evidence language

**Implemented** means present in identified source. **Demonstrated** names an executed check and revision. **Intended** identifies a goal without implying implementation. **Unresolved** names a missing decision or acceptance gate. A host build or WPF rendering never establishes manual, clean-machine or physical acceptance.

Production exposes only offline Trail candidate inspection. Display has no provider; production signer trust, admission and device/install/recovery authority remain unavailable. Internal fixture admission, fake adapters and the actual host engine support host validation; they are not production wiring.
